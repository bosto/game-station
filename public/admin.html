🤖 Agent 发布说明

Agent 在写好游戏后,把本地目录发布上来即可(无需本后台):
① 命令行发布(推荐):
  GAME_STATION_TOKEN=你的令牌 node scripts/publish.mjs /path/to/game-dir --title "游戏名" --publish
② 或直接调用 HTTP API:
  curl -X POST http://127.0.0.1:3210/api/games -H "x-admin-token: 令牌" -H "Content-Type: application/json" -d '{"slug":"my-game","title":"我的游戏"}'
  curl -X PUT --data-binary @index.html "http://127.0.0.1:3210/api/games/my-game/files/index.html" -H "x-admin-token: 令牌"
  curl -X PATCH http://127.0.0.1:3210/api/games/my-game -H "x-admin-token: 令牌" -H "Content-Type: application/json" -d '{"playable":true}'
完整接口与规范见项目根目录 AGENTS.md。
